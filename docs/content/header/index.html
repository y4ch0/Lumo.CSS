Header

The main header element for the page. Can be made sticky by adding the .is-fixed class.

Default

  • Page 1
  • Page 2
  • Page 3
<header class="is-fixed">
        <div class="container">
            <a href="index.html"><img src="/LumoCSS.svg" alt="Lumo.CSS logo" height="65" id="page-logo">
            </a>
            <nav aria-label="Main navigation">
                <button type="button" role="menu" aria-label="Open navigation" aria-expanded="false"></button>
                <ul>
                    <button type="button" aria-label="close"></button>
                    <li><a href="/page1">Page 1</a></li>
                    <li><a href="/page2">Page 2</a></li>
                    <li><a href="/page3">Page 3</a></li>
                </ul>
            </nav>
        </div>
    </header>

Header can have toggled glass backdrop effect by adding .glass class to header tag.
