Customize

You can customize Lumo.CSS by editing :root variables with --lumo prefix. Full list of these variables set to its default value is below.

    --lumo-secondary-color: #007AFF;
    --lumo-text-light: #FFFFFF;
    --lumo-text-dark: #1d1d1d;
    --lumo-primary-button-text: var(--lumo-text-dark);
    --lumo-secondary-button-text: var(--lumo-text-light);
