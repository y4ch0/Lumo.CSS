# Lumo.CSS

Lumo.CSS is lightweight CSS and JS framework made for building semantic web interfaces, while keeping its wide range of usage in web development.

It features set of styled components and default HTML objects to make creating a website even easier, where each element has its own variant to change its design.

## Easy to learn, because you don't have to.
Lumo relies on semantic HTML structure to build web interfaces accessible for everyone. Its design lets developer skip the matter of accessibility in the website and focus on better user experience.

## Lightweight and fast
CSS stylesheet with Javascript gzipped is only 14KB. It lets browser load this framework instantly, so interface of the project is immediately rendered.
